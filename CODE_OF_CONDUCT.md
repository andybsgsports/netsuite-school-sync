# Code of Conduct

This repository is a private, internally-maintained tool for BSG Sports. It
isn't a public community project, but the same baseline applies to anyone
who interacts with it — issues, pull requests, code review comments, or
commit messages:

- Be respectful and professional. Critique code and ideas, not people.
- Assume good faith. Most bugs and disagreements are honest mistakes, not
  malice.
- No harassment, discriminatory language, or personal attacks, in this
  repository or in any related communication.
- Keep discussion on-topic and constructive — if something needs a longer
  conversation, take it outside the PR/issue thread.

## Reporting

If you experience or witness behavior that violates this, contact the repo
owner (andybsgsports) directly. Reports will be handled privately and
taken seriously.

## Scope

This applies within the repository (issues, PRs, commits, code review) and
in any other space where someone is representing this project.
